Control by design

Automation should be safe to operate.

The MVP is designed to make the safe path the easy path.

Publishing guardrails

Dry-run is the default.
Moderation runs before publishing.
Human approval is required for live publishing.
Failed policy checks stay out of the publish path.

Credential hygiene

No OAuth tokens in source control.
Secrets use environment variables and GitHub Secrets.
AI providers do not receive raw platform credentials.
Live platform behavior is validated before production use.
Roadmap

Start focused. Scale behind adapters.

Prove the core workflow with Meta before adding platform complexity.

Phase 1 · Meta

Instagram + Facebook Page, AI drafts, moderation, approval, dry-run publishing and analytics.

Phase 2 · Expansion

LinkedIn + X using the same platform-neutral workflow and adapter contracts.

Phase 3–4 · Intelligence

TikTok + YouTube, then analytics-driven topic scoring and recommendation loops.
